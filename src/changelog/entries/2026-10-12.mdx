**Merged this week.** Availability depends on the installed or deployed release.

## Highlights

- [Persistent managed agents](#persistent-managed-agents) — Keep conversations and working files between sessions.
- [Compatible release downloads](#compatible-release-downloads) — Deliver the right update format to each Nexus installation.
- [Shared workspace and export](#shared-workspace-and-export) — Reuse project context and download the full matching selection.

## Nexus

### Persistent managed agents

OpenCode agents now retain conversations and working files in shared runtimes. Pause, Stop and Delete affect the selected session. Runtime startup and crash-loop fixes are included. Agents sharing an endpoint/model connection share a trust boundary.

### Clearer connection errors

Test and Save now show field-level validation, focus the invalid input and suggest valid connection names. For runtime failures, Show details reveals a bounded, redacted explanation.

### Readable notes and conversations

Notes and agent answers render Markdown, tables and code. Long conversations keep the composer and Send action visible. Open a note to read its full content in a scrollable view.

### Silent MCP renewal

OAuth clients can renew access without repeating browser approval. Refresh tokens rotate on use; renewal rechecks device access and rejects replay. Clients must retain the replacement refresh token after each renewal.

### Complete appliance updates

One signed release now covers images and deployment configuration, with progress tracking, health checks and recovery after interrupted activation. Older installations use update, reboot, then Finish Update for the same release.

## Cloud

### Compatible release downloads

Cloud selects complete archives for capable Nexus updaters and compatibility images for older clients. Existing image-only publications keep working. Deploy the compatible Cloud service before publishing complete releases.

## Stream

### Shared workspace and export

The authenticated workspace now uses project-shared Filters and dashboards, typed discovery and full-result JSON/CSV/TSV export. Widgets reference Filter IDs; conflicting edits preserve drafts. Exports cover all matching pages, capped at 10,000 events and 32 MiB.

### Project context over MCP

Account sessions gain five read tools for project context, health, dashboards and documentation, with membership checks on each request. Account clients select their project using X-Plotune-Project-Id.

### MCP OAuth consent

OAuth-capable clients can request project access through a consent screen showing the application, destination and permissions. Activate the authorization service and consent page together before use.

### Bounded analysis jobs

MCP adds bounded aggregation and persisted, paged results with coverage reporting, cancellation and expiry. Numeric metrics remain type-strict. Use events_aggregate, analysis_jobs_get and analysis_jobs_cancel; check coverage before interpreting results.
