# Edition template

Create drafts outside `src/changelog/entries` and `public`. Use
`scripts/changelog/draft.cjs` with private selection/evidence inputs. Only checked
plain Markdown is accepted; see [the workflow](../changelog.md).

Frontmatter: title, summary, weekStart (UTC Monday), publishedAt, status: draft,
products: Nexus and/or Stream, media: at most two reviewed descriptors.

## Product name

### Available now

A short change title, the practical benefit and a public usage/documentation link.

### Preview — not yet released

Only explicitly eligible previews. Explain what can be explored today and avoid
promises or implying general availability. Omit empty sections.
