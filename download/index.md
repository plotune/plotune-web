# Download Plotune Desktop

The desktop app for local visualization and engineering data workflows.  Choose your operating system and package.

 A tiny test lab with a small rig on a bench.

- ### Debian/Ubuntu (.deb)

Recommended for Debian-based distributions. Easy installation with APT package manager.

Version

Latest

```
$ curl -fsSL https://plotune.net/install.sh | bash
```

Installation steps

- Option 1: Click Download for .deb package

- Option 2: Run install script: curl -fsSL https://plotune.net/install.sh | bash

- Install with: sudo dpkg -i plotune*.deb

- Fix dependencies: sudo apt-get install -f

[Download Now](https://github.com/plotune/plotune-dl/releases/latest)[View Install Script ↗](https://plotune.net/install.sh)

- ### Arch Linux (AUR)

For Arch and Arch-based distributions. Install via AUR helper with automatic updates.

Version

Latest

Size

Auto

```
$ yay -S plotune-bin
```

Installation steps

- Using AUR helper (recommended): yay -S plotune-bin

- Manual install: git clone https://aur.archlinux.org/plotune-bin.git

- cd plotune-bin && makepkg -si

- Run: plotune

[Download Now](https://github.com/plotune/plotune-dl/releases/latest)[AUR Help ↗](https://wiki.archlinux.org/title/Arch_User_Repository)

- ### Snap Package

Universal package for most Linux distributions. Sandboxed and auto-updating.

Version

Latest

```
$ sudo snap install plotune
```

Installation steps

- Open terminal

- Run: sudo snap install plotune

- Or click below for Snap Store

- Launch from applications menu

[Download Now](https://github.com/plotune/plotune-dl/releases/latest)[Snap Guide ↗](https://snapcraft.io/docs)

- ### Standalone Binary

Generic Linux binary. No installation needed - download and run directly.

Version

Latest

```
$ ./plotune
```

Installation steps

- wget https://github.com/plotune/plotune-dl/releases/latest/download/plotune-linux-x86_64.tar.gz

- Extract: tar -xzf plotune-linux-x86_64.tar.gz

- cd plotune-linux-x86_64

- Run: chmod +x plotune && ./plotune

[Download Now](https://github.com/plotune/plotune-dl/releases/latest/download/plotune-linux-x86_64.tar.gz)

Need help?  Check out our [documentation](https://www.plotune.net/docs) or join our [community Discord](https://discord.gg/plotune) for support. Installer scripts are open source.
