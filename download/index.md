### Debian/Ubuntu (.deb)

 DEB

v1.0.58.3  8.5 MB  curl -fsSL https://plotune.net/install.sh | bash

Recommended for Debian-based distributions. Easy installation with APT package manager.

#### Installation Steps:

- 1  Option 1: Click Download for .deb package

- 2  Option 2: Run install script: curl -fsSL https://plotune.net/install.sh | bash

- 3  Install with: sudo dpkg -i plotune*.deb

- 4  Fix dependencies: sudo apt-get install -f

### Arch Linux (AUR)

 AUR

v1.0.58.3  Auto  yay -S plotune-bin

For Arch and Arch-based distributions. Install via AUR helper with automatic updates.

#### Installation Steps:

- 1  Using AUR helper (recommended): yay -S plotune-bin

- 2  Manual install: git clone https://aur.archlinux.org/plotune-bin.git

- 3  cd plotune-bin && makepkg -si

- 4  Run: plotune

[Download Now](https://aur.archlinux.org/packages/plotune-bin)[AUR Help](https://wiki.archlinux.org/title/Arch_User_Repository)

### Standalone Binary

 BINARY

v1.0.58.3  8.5 MB  ./plotune

Generic Linux binary. No installation needed - download and run directly.

#### Installation Steps:

- 1  wget https://github.com/plotune/plotune-dl/releases/latest/download/plotune-linux-x86_64.tar.gz

- 2  Extract: tar -xzf plotune-linux-x86_64.tar.gz

- 3  cd plotune-linux-x86_64

- 4  Run: chmod +x plotune && ./plotune
